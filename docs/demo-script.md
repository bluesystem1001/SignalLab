# SignalLab 2–3 分钟无剪辑答辩脚本

本脚本用于阶段 8 的现场备份录屏，目标时长约 2 分 40 秒。它与 `data/samples/demo_analysis.sig` 不同：后者是 SignalScript 源码，本文件是操作和讲解顺序。

## 录制前准备

1. 使用已经通过发布验证的 `SignalLab-1.0.0-rc1-windows-x64` 独立目录，不从构建目录运行。
2. 保留包内样例、迁移、配置、许可证和空白数据库模板；确认活动路径 `data/signallab.sqlite3` 尚不存在，使首次启动自动创建内置 1 kHz 信号。
3. 确认 `data/script_outputs/` 中没有与演示相关的残留输出；本次使用不带 `save` 的可重复脚本。
4. 屏幕缩放、窗口大小和录制区域提前固定。录制期间不剪辑、不等待编译、不展示个人目录或其他敏感信息。

## 时间线与讲解词

### 0:00–0:20 启动和项目概览

- 启动 `SignalLab.exe`，指出左侧项目列表和首次创建的 1 kHz 演示信号。
- 简短说明程序是离线、一维、等间隔采样的信号分析工具，项目数据写入本地 SQLite。

### 0:20–0:50 单窗口导入

- 单击“导入 CSV”，选择 `data/samples/example_signal.csv`。
- 保持逗号、表头、时间列 1、数值列 2，更新预览并指出 21 个样本、1000 Hz。
- 确认导入；任务完成后选择新信号，说明预览、校验和提交都在同一窗口完成。

### 0:50–1:15 同轴对比和时间轴滑动

- 把导入信号作为主信号，选择内置 1 kHz 信号作为对比。
- 指出主信号实线、对比信号虚线，二者以各自相对 `t=0` 共享秒轴，不做重采样。
- 横向放大一次，拖动图下时间轴滑动条，再复位；说明缩放和平移只改变 X 轴窗口。

### 1:15–1:40 后台分析与追溯

- 单击“后台分析所选信号”，切到任务中心观察排队/运行/成功。
- 返回分析结果，指出均值、RMS、主频等；打开分析历史，指出参数 JSON、算法版本和哈希。

### 1:40–2:00 FIR 派生信号

- 对 1000 Hz 样例提交低通 FIR：截止 100 Hz、63 个抽头。
- 任务完成后指出新派生信号已持久化并自动选中；参数和来源可追溯。

### 2:00–2:25 SignalScript

- 打开 `data/samples/demo_analysis.sig`，运行脚本。
- 指出诊断、变量、输出、AST 和结构化图形共用同一服务；脚本没有 Shell、网络或任意路径能力。

### 2:25–2:40 收尾

- 打开 `docs/user-guide.md` 或包内用户手册位置，说明样例、空白数据库模板、期望结果和许可证均随包提供。
- 正常关闭程序，确认进程退出。最后一句说明自动化测试、30 分钟稳定性和干净包验证另有日志证据。

## 失败时的处理

录制中如果出现错误，不要剪切后拼接成“成功”视频。停止本轮，保存错误画面和日志，修复并重新从独立目录完整录制。若只是操作失误，可从头开始新的一轮，但最终交付的视频必须是一段连续录像。
