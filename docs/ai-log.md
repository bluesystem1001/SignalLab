## 2026-09-08：阶段 2 文件导入与信号管理

- AI 协助：实现流式 CSV 校验与读取、PCM16 WAV 解析、SHA-256、导入预览、内容寻址存档、信号列表和按像素极值下采样。
- CSV 规则：支持逗号/Tab、可选表头、时间列或显式采样率、引号转义；错误包含源路径和从 1 开始的行列。预览会验证完整文件，但只保留指定数量的预览行。
- WAV 规则：支持 RIFF/WAVE PCM 16-bit 单/双声道及左、右、平均选择；校验 chunk 边界、块对齐和字节率，错误包含源路径和 byte offset。
- 存档一致性：阶段 2 当时先创建唯一临时快照，再对同一快照进行哈希和解析，最后原子重命名为 `data/imports/<hash>.<扩展名>`；失败和重复路径均清理临时文件，损坏的既有哈希文件不会被覆盖。阶段 4 后的新命名见下文。
- 显示性能：百万样本测试确认绘图点不超过 `2 × pixelWidth`，并保留每个桶的最小值、最大值和时间顺序。
- 构建验证：Debug 与 Release 均无警告构建成功，分别通过 41/41 项测试；两种配置的 `-j 8` 并行复验也全部通过。
- 运行验证：Debug 与 Release 都创建 `SignalLab 0.2.0` 窗口，保持响应并以退出码 0 正常关闭。
- 架构验证：`core` 源码没有 Qt 引用，核心测试程序没有 Qt DLL 导入；主程序仍为 Windows GUI subsystem。
- 环境复验：完整 `pacman -Q` 为 167 项，与阶段 0 快照完全一致；GCC 16.1.0、CLion GDB 16.3 和 Git 2.54.0 均可用。
- 用户流程：按用户最新要求，阶段 2 备份后停止，只有收到验收通过指令才开始阶段 3。
- 人工验收边界：当前会话的 Windows UI 控制通道不可用，因此未自动点击原生文件对话框；README 已给出逐步人工验收清单，服务层导入、项目列表接线和窗口运行分别已有自动化测试或静态审计证据。

## 2026-09-08：阶段 3 核心算法闭环

- 用户批准：收到“进行阶段三”后，阶段 2 视为通过验收；本次只实施阶段 3，完成备份后停止等待下一次验收。
- AI 协助：实现去直流、归一化、截取、Rect/Hann/Hamming 窗、自研 radix-2 FFT、单边幅值/功率谱、基本特征、频带能量、峰值检测、FIR 低通/高通、SNR/THD、同步分析服务和频谱图表。
- 数值口径：总体方差分母为 `N`；幅值用窗相干增益校正；非 2 次幂先按原长度加窗再补零；峰值使用三点对数抛物线插值；SNR 把谐波计入非基频功率，THD 只累计谐波保护频点。
- 边界审查：增加 FFT 输入/输出有限值检查、频谱派生值有限检查、公开 `Spectrum` 的窗类型检查，以及分析服务的 THD 阶数和保护频点参数检查。
- 测试验证：Debug 与 Release 均无警告构建成功并通过 101/101 项测试；覆盖常量、冲激、双音、固定种子白噪声、非 2 次幂、空输入、FIR 边界、错误参数和数值溢出。
- 精度验证：48 kHz、65,536 点、1 kHz、幅值 1 的正弦实测主峰为 1000.011 Hz、幅值 1.018；频率误差 0.011 Hz 小于一个 FFT 频点 0.732 Hz，幅值误差 1.776% 小于 2%。
- Release 基准：Intel Core i9-14900HX、Windows 11 x64、GCC 16.1.0、`-O3 -DNDEBUG`；3 次预热、每轮 20 次、独立运行 5 轮。平均耗时的五轮中位数为 radix-2 FFT 1.806 ms、完整 Hann 单边频谱 4.895 ms。
- 解耦验证：算法源码没有 Qt 引用，算法测试程序没有 Qt DLL 导入；构建和测试没有 NumPy、MATLAB、FFTW 或其他数值运行时依赖。
- 运行验证：Debug 与 Release 都创建 `SignalLab 0.3.0` 窗口，保持响应，正常关闭并返回退出码 0。
- 人工验收边界：自动化测试覆盖完整同步分析服务，进程级检查覆盖窗口启动/响应/关闭；按钮点击、页签和图表观感按 README 的阶段 3 清单由用户最终验收。

## 2026-09-09—2026-09-11：阶段 4 SQLite 持久化与追溯

- 用户批准：收到“进行阶段四”和继续生成指令后，开始阶段 4；本次不提前实施阶段 5，阶段备份后仍需停止等待用户验收。
- AI 协助：新增 repository 抽象、文件系统仓库、SQLite 连接/迁移执行器、信号/任务/脚本历史仓库，并把持久化信号和历史任务接入启动流程与 GUI。
- 依赖边界：`signallab_app` 现在只依赖 repository 接口，不再链接 `signallab_io`；`main.cpp` 组装 `FilesystemFileRepository` 和 SQLite 仓库。ADR 0006 的阶段性例外已正式关闭。
- 数据库初始化：`001_init.sql` 建立 `signal_source`、`signal_record`、`analysis_task`、`feature_result`、`file_version`、`script_history` 和 `operation_log`，迁移执行器用 `schema_migration` 记录版本。连接开启外键、WAL 和 5000 ms busy timeout，并检查 Qt 线程归属。
- 导入模型：原始文件版本与逻辑信号记录已分开。相同内容只存档一份，但可通过不同 CSV 列/采样率或 WAV 声道选项产生多个逻辑信号；内容和解析选项都相同时仍拒绝重复。新存档固定为 `data/imports/<sha256>.source`，旧扩展名存档保持原路径复用，避免旧数据库路径失效。
- 可复现性：导入与分析参数使用规范化 JSON；任务保存算法名/版本、输入/输出 SHA-256 和 UTC 时间。“历史任务”页签可查看这些字段和持久化特征。
- 失败语义：信号注册使用事务；特征结果与 `SUCCEEDED` 状态一起提交。注入特征写入失败时，事务不留任何孤立 `feature_result`，任务另行记为 `FAILED`。
- 重启语义：启动时先将遗留 `RUNNING` 任务改为 `INTERRUPTED`，再从 SQLite 恢复信号；已导入文件的存档路径和内容哈希会在恢复时复核。分析只接收记录编号，再从信号仓库加载可信样本和输入哈希。
- 审查修正：补齐采样率参与输入哈希、规范 SHA-256 小写约束、迁移整文件回滚、PRAGMA 回读、失败状态二次写入错误传播、安全补偿删除、固定 `.source` 新存档名和旧存档路径兼容；对应边界均有自动化测试。
- 测试验证：Debug 与 Release 均无警告构建成功并通过 127/127 项测试；覆盖迁移幂等、SQL 连接配置/线程归属、事务回滚、旧路径恢复、信号/任务恢复、稳定输出哈希、NaN/重复特征失败和启动中断。
- 运行验证：Debug GUI 连续启动两次均保持运行；每次检查均为 `integrity=ok`，`schema_migration`、内置信号源和信号记录数量保持为 1，已有任务历史保持为 2。
- 环境复验：完整 `pacman -Q` 为 167 项，与阶段 0 快照逐项一致；GCC 16.1.0、Qt 6.11.1、GoogleTest 1.17、SQLite、Git 2.54.0、CLion CMake 4.2.2/Ninja 1.13.2 和经批准的 CLion GDB 16.3 均可用。
- 阶段交付（当时状态）：使用 `stage-4-complete` 与 `v0.4` 标记阶段版本并生成外部 Git bundle。工程当时停在阶段 4 用户验收点，阶段 5 尚未开始；该状态已由下方 2026-09-15 的续接记录取代。

- 用户目标：在先前会话丢失后继续阶段 5，先复核阶段 4，再同步实施计划和项目文档。

- 调度实现：新增独立计算/I/O 队列、线程池、`Scheduler`、任务快照、限频进度、协作取消和终态重试。成功返回作为提交边界，晚到的停止请求不会把已提交成功倒退为取消。
- 后台接线：`BackgroundAnalysisService` 把分析送入计算池，`BackgroundFileService` 把 CSV/WAV 预览和导入送入 I/O 池；`MainWindow` 通过受保护事件队列、`QPointer` 和 Qt queued 调用回到 GUI 线程更新控件，并提供“后台任务”列表、取消和重试操作。
- 数据库线程：新增 `DatabaseExecutor`，在专属线程创建、使用和销毁 Qt SQL 连接及具体仓库，来自 GUI 和工作池的仓库请求统一串行代理。`002_task_scheduler.sql` 保留既有任务/特征数据并加入 `CANCELLED` 约束。
- 一致性与退出：导入服务串行保护“存档提升—数据库注册—补偿删除”边界；程序退出时先清除界面通知，再关闭调度器并等待工作线程，最后排空并关闭数据库执行器。
- 审查修正：每个任务的通知在锁内排序入队、锁外串行调用观察者；观察者从提交线程或工作线程同步委托另一线程关闭时只发起停止，主退出路径再用 `shutdownAndWait()` 明确 join。后台分析和文件结果按调度任务编号隔离并在终态移出，避免并发重试串结果和大频谱长期保留；界面只显示与当前所选信号匹配的完成结果。数据库信号读取接入停止令牌，BLOB 哈希和解码分块检查取消，代理在数据库命令真正静止后才返回取消。
- 自动化覆盖：新增或更新的用例覆盖队列与线程池、计算/I/O 隔离、状态和进度顺序、排队/运行取消、终态重试、观察者重入及并发关闭、重复 100% 限频、后台服务事件、数据库线程代理、真实 FFT 与大 BLOB 读取中途取消、三大分析期间 Qt 事件循环响应，以及运行中退出刷盘。
