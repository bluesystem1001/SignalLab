## 2026-09-08：阶段 2 文件导入与信号管理

- AI 协助：实现流式 CSV 校验与读取、PCM16 WAV 解析、SHA-256、导入预览、内容寻址存档、信号列表和按像素极值下采样。
- CSV 规则：支持逗号/Tab、可选表头、时间列或显式采样率、引号转义；错误包含源路径和从 1 开始的行列。预览会验证完整文件，但只保留指定数量的预览行。
- WAV 规则：支持 RIFF/WAVE PCM 16-bit 单/双声道及左、右、平均选择；校验 chunk 边界、块对齐和字节率，错误包含源路径和 byte offset。
- 存档一致性：阶段 2 当时先创建唯一临时快照，再对同一快照进行哈希和解析，最后原子重命名为 `data/imports/<hash>.<扩展名>`；失败和重复路径均清理临时文件，损坏的既有哈希文件不会被覆盖。阶段 4 后的新命名见下文。
- 显示性能：百万样本测试确认绘图点不超过 `2 × pixelWidth`，并保留每个桶的最小值、最大值和时间顺序。
- 构建验证：Debug 与 Release 均无警告构建成功，分别通过 41/41 项测试；两种配置的 `-j 8` 并行复验也全部通过。
- 运行验证：Debug 与 Release 都创建 `SignalLab 0.2.0` 窗口，保持响应并以退出码 0 正常关闭。
- 架构验证：`core` 源码没有 Qt 引用，核心测试程序没有 Qt DLL 导入；主程序仍为 Windows GUI subsystem。
- 环境复验：完整 `pacman -Q` 为 167 项，与阶段 0 快照完全一致；GCC 16.1.0、CLion GDB 16.3 和 Git 2.54.0 均可用。

## 2026-09-08：阶段 3 核心算法闭环

- 用户批准：收到“进行阶段三”后，阶段 2 视为通过验收；本次只实施阶段 3，完成备份后停止等待下一次验收。
- AI 协助：实现去直流、归一化、截取、Rect/Hann/Hamming 窗、自研 radix-2 FFT、单边幅值/功率谱、基本特征、频带能量、峰值检测、FIR 低通/高通、SNR/THD、同步分析服务和频谱图表。
- 数值口径：总体方差分母为 `N`；幅值用窗相干增益校正；非 2 次幂先按原长度加窗再补零；峰值使用三点对数抛物线插值；SNR 把谐波计入非基频功率，THD 只累计谐波保护频点。
- 边界审查：增加 FFT 输入/输出有限值检查、频谱派生值有限检查、公开 `Spectrum` 的窗类型检查，以及分析服务的 THD 阶数和保护频点参数检查。
- 测试验证：Debug 与 Release 均无警告构建成功并通过 101/101 项测试；覆盖常量、冲激、双音、固定种子白噪声、非 2 次幂、空输入、FIR 边界、错误参数和数值溢出。
- 精度验证：48 kHz、65,536 点、1 kHz、幅值 1 的正弦实测主峰为 1000.011 Hz、幅值 1.018；频率误差 0.011 Hz 小于一个 FFT 频点 0.732 Hz，幅值误差 1.776% 小于 2%。
- Release 基准：Intel Core i9-14900HX、Windows 11 x64、GCC 16.1.0、`-O3 -DNDEBUG`；3 次预热、每轮 20 次、独立运行 5 轮。平均耗时的五轮中位数为 radix-2 FFT 1.806 ms、完整 Hann 单边频谱 4.895 ms。
- 解耦验证：算法源码没有 Qt 引用，算法测试程序没有 Qt DLL 导入；构建和测试没有 NumPy、MATLAB、FFTW 或其他数值运行时依赖。
- 运行验证：Debug 与 Release 都创建 `SignalLab 0.3.0` 窗口，保持响应，正常关闭并返回退出码 0。
- 人工验收边界：自动化测试覆盖完整同步分析服务，进程级检查覆盖窗口启动/响应/关闭；按钮点击、页签和图表观感按 README 的阶段 3 清单由用户最终验收。
