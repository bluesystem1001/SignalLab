# ADR 0003：通过 QSQLITE 访问 SQLite

- 状态：已接受
- 日期：2026-09-04

## 背景

SignalLab 需要保存信号来源、任务、特征、脚本历史和操作日志。GUI 已使用 Qt，如果再单独维护一套 SQLite 封装，会增加初学者需要理解的接口和链接配置。

## 决定

- 使用 `Qt6::Sql` 和 QSQLITE 驱动访问数据库。
- 当前 MSYS2 SQLite 包为 `mingw-w64-x86_64-sqlite3 3.53.2-1`。
- 应用不再直接链接独立的 `sqlite3` 库。
- SQL 使用预编译语句和参数绑定。
- 写入使用事务；失败时完整回滚。
- 每个 Qt SQL 连接只在所属线程内创建、使用和销毁。

## 初学者约定

数据库代码集中放在 `database` 基础设施模块。GUI 不直接写 SQL，应用服务只依赖仓库接口。这样可以按“界面 → 服务 → 仓库实现”的顺序阅读代码。

## 结果

选择 QSQLITE 能复用 Qt 的连接和错误处理接口，并避免链接两份 SQLite。代价是必须在发布包中检查 `sqldrivers` 插件，且不能把数据库连接对象跨线程传递。
