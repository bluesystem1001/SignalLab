# ADR 0001：统一使用 C++20

- 状态：已接受
- 日期：2026-09-04

## 背景

SignalLab 需要只读样本视图、线程取消和常用数学常量。项目还需要在所有模块中保持相同语言标准，避免某个目标能编译而另一个目标不能编译。

## 决定

所有自研目标统一使用 C++20：

- 设置 `CMAKE_CXX_STANDARD 20`。
- 设置 `CMAKE_CXX_STANDARD_REQUIRED ON`。
- 设置 `CMAKE_CXX_EXTENSIONS OFF`。
- 自研库通过 `target_compile_features(... PUBLIC cxx_std_20)` 传播要求。

可以使用 `std::span`、`std::jthread`、`std::stop_token`、`std::numbers` 和 `std::bit_ceil`，但只在它们让代码更清楚时使用。

## 初学者约定

- 优先使用普通函数、清楚的类型和直接的循环。
- 不为了展示语法而使用复杂模板或元编程。
- 返回 `std::span` 时，底层容器必须比该视图活得更久。
- 一个项目只维护一种任务取消方式。

## 结果

C++17 缺少计划需要的部分标准库能力；C++23 会提高环境要求。C++20 在功能和教学可读性之间更合适。
