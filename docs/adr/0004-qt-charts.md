# ADR 0004：首版使用 Qt Charts

- 状态：已接受
- 日期：2026-09-04

## 背景

首版需要在 QWidget 程序中显示时域和频域曲线。课程周期有限，图表应尽快可用，同时不能把业务计算写进绘图库。

## 决定

- 使用 `mingw-w64-x86_64-qt6-charts 6.11.1-1`。
- Qt Charts 只负责显示、缩放、游标和图片导出。
- FFT、特征、坐标计算和显示下采样放在 GUI 之外的模块。
- 百万点数据先按像素桶提取最小值和最大值，不直接全部提交给图表。

## 许可证约束

实施计划按 Qt Charts 的 GPLv3 约束记录。课程源码交付应保留第三方许可说明；若需要闭源发布，必须提前确认 Qt 商业许可或改用合适的替代方案。

## 结果

Qt Charts 与现有 QWidget 技术栈一致，初学者不需要额外学习另一套窗口框架。代价是需要主动控制大数据量绘制性能，并在发布前复核许可证。
